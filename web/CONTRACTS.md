# web/ — frontend contracts

The UI is React + TypeScript, built by Vite. MUI owns standard controls and
dialogs, TanStack Query owns server state/caching/polling, ECharts renders the
treemap, and React Flow renders class reference graphs. The production artifact
is **`web/dist/index.html`**, generated by `npm run build`.

## Ownership map

```
web/src/main.tsx                  React root, QueryClient, MUI theme
web/src/app/                     shell, tabs, current dump, visualization context
web/src/components/              shared UI primitives and ECharts adapter
web/src/data/types.ts            API/payload/repository types
web/src/data/http.ts             the only fetch/error conversion boundary
web/src/data/repository.ts       HTTP + inline repositories and lifecycle calls
web/src/data/queries.ts          query keys, query hooks, mutations, polling
web/src/data/RepositoryContext*  selects HTTP versus inline data access
web/src/features/dumps/          dump picker/filter/tag/lifecycle UI
web/src/features/jobs/           jobs, progress, cancellation and logs
web/src/features/classes/        server-paged class table + analysis
web/src/features/treemap/        ECharts treemap
web/src/features/compare/        dump comparison + retained-set drilldowns
web/src/features/shapes/         Shapes tab, controls, details, React lifecycle
web/src/viz/                     class visualization dialog and React renderers
web/viz/                         shared pure layout/prepare/scene algorithms and
                                 high-volume Shapes Canvas engine (not a second UI)
web/vite.config.ts               dev API proxy + single-file production build
web/dist/index.html              sole production artifact (generated, gitignored)
```

`backend/http.py` serves only `web/dist`; it never serves TSX source. During
development, `npm run dev` serves the React app on port 5173 and proxies `/api`
to the Python server on port 8321.

## Component and state rules

1. Server interaction goes through a repository and TanStack Query. Components
   do not call `fetch`, create bespoke cache maps, or hand-roll polling timers.
   Query keys always include the dump id and all parameters affecting the
   response. Analysis success invalidates affected queries.
2. UI state belongs to React. Use declarative JSX, not `innerHTML`, DOM
   rebuilding, global mutable registries, or window globals. Data-derived text
   is escaped by React. The only global payload is the snapshot input
   `window.__INLINE__`, read once by the app.
3. MUI supplies ordinary buttons, fields, tables, tabs, dialogs, progress and
   alerts. ECharts/React Flow own chart and graph interaction. Do not rebuild
   their built-in behavior locally.
4. Pure algorithms are separated from rendering. The existing iterative Shapes
   layout/spatial indexes and class graph layout functions remain reusable and
   node-testable. High-volume Shapes rendering stays on Canvas with viewport
   culling/bitmap LOD; never convert millions of shapes to React/SVG elements.
   Its controls/details and effect cleanup are React-owned.
5. Every async path ends in data, an explicit error, a not-analyzed/not-ready
   state, or a loading state with retry/terminal handling. Requests must not
   silently spin forever. Stale data from another dump must never be presented
   as the current dump.
6. Overview tabs work in busy states once the backend data bundle exists;
   remote/failed dumps are blocked client-side and a 409 retries with a clear
   loading/error state. Analysis remains gated on READY and is absent in
   snapshot mode.
7. Renderer effects clean up observers, listeners, animation frames, timers,
   Canvas backing stores and other large references. Analysis polling is query
   owned and does not reopen a disposed dialog.

## Repository result contract

`data/http.ts` returns a discriminated result for every HTTP call:

```ts
{ ok: true, data } |
{ ok: false, status, code, error, data? }
```

Network failures use `status: 0, code: 'network'`; 204 becomes `data: null`.
`unwrap()` converts a failed result to `ApiError` for TanStack Query. Raw fetch
errors are not rendered piecemeal across components.

```ts
// Dump lifecycle
list()                    -> Result<DumpInfo[]>       GET /api/dumps
startDownload(id)         -> Result<Job>
cancelDownload(id)        -> Result<{id,cancelled}>
delete(id)                -> Result<null>
setTags(id,tags)          -> Result<{id,tags}>
jobs()                    -> Result<Job[]>             GET /api/jobs
cancelJob(id)             -> Result<{id,cancelled}>

// DumpDataRepository (HTTP or inline)
trees(id)
classes(id,{filter,sort,page})
composition(id,className)
anatomy(id,className,{samples})
compare(aId,bId)
analyze(id,className,{samples,anatomy})
shapes(id)
shapesAnalyze(id)
```

The payload shapes are typed in `web/src/data/types.ts`. Successful query data
is cached by TanStack Query with dump-scoped keys. Job mutations are not cached
as reads. The inline repository implements the same interface over the
snapshot payload and returns `code: 'snapshot'` for server-only operations.

## Visualization contract

`AppContext.openViz(kind,dumpId,className)` is the single entry point. The MUI
`VisualizationDialog` switches among `anatomy`, `hierarchy`, `graph`, and
`flow`, keys queries by kind/dump/class/params, and owns sample-analysis job
state. Pure prepare functions produce view models; React components render
those models and use `setParams` to re-slice them.

Graph and Flow use their tested pure layouts inside React Flow. Selection,
reference details, sample/global scaling, cycle filtering, minimum-retained
filtering, split copies, and persisted pin edits remain declarative UI state.
The heap-wide Shapes explorer is intentionally a tab, not a class popup.

## Snapshot mode

Build first:

```bash
npm ci && npm run build
python3 -m backend.snapshot --dump <id> --out report.html
```

Vite's single-file plugin inlines application JS and CSS. `backend.snapshot.py`
reads that exact artifact and inserts a classic payload script **before** the
application module. Payload JSON escapes `</`, U+2028 and U+2029 so data cannot
terminate its script tag. No source-module rewriting or Python-side JS bundling
remains.

When `window.__INLINE__` exists:

- `makeInlineRepository(payload)` is injected through `RepositoryProvider`;
- dump-list/job polling and server mutations are disabled;
- dump selection is fixed to the snapshot name;
- Compare and analysis/download affordances are hidden;
- the same Classes, Treemap, Shapes and class visualizations read inline data;
- no API request is needed, including when opened as `file://`.

Snapshot payload:

```ts
{
  name: string;
  stats: HeapStats;
  trees: {dom?: TreeNode; hist?: TreeNode};
  classes: [display,count,shallow,retained,composition,anatomies,lambdas][];
  comps: Record<string,CompositionPayload>;
  anats: Record<string,AnatomyPayload>;
  shapes: ShapesPayload | null;
}
```

## Verification

- `npm run typecheck` — strict TypeScript.
- `npm test` — Vitest component/repository tests plus the original iterative
  layout/scene node tests.
- `npm run build` — production TypeScript + single-file Vite build; CI runs it
  before Python snapshot tests.
- Python snapshot tests exercise the real generated artifact and payload
  escaping; HTTP static tests prove development source is not served.
- Browser smoke should cover a real dump and an offline `file://` snapshot,
  including console errors and unwanted network requests.
